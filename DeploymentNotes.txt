There are four parts to this software:

recovery_worker.py (a service that heals failures)
worker.py (performs the main research)
FAST API (exposes an API to control the researcher from api/main)
Frontend (a web UI for admins and users)


The below instructions are for Windows.  The app should run on Linux too, but hasn't been tested.
I've kept most things platform agnostic.  Note that these instructions are for development on a single server.  In
production the settings for the Caddy frontend will need to be modified.  If you want to expose 
the FAST API for integration purposes, it too will need to be modified.

Download and install the latest version of python, node and npm.

This app uses a MSSQL backend over TCP/IP and requires an SQL account.
Create a DB, call it 'Researcher' and allow the user account access.

Download:
ODBC Driver 18 for SQL Server
https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server?view=sql-server-ver17
Add the SQL account details to .env and run create_database.py.

Worker Recovery Service

Uses Windows Service Wrapper

7. Rename the WinSW-x64.exe to LGResearchRecovery.exe and place in C:\Services\LGResearchRecovery folder


8. Create a file called LGResearchRecovery.xml in the LGResearchRecovery folder.  Replace
the text with that provided below:

<service>
  <id>LGResearchRecovery</id>
  <name>LG Research Recovery Worker</name>

  <description>
    Continuous recovery coordinator for LG Researcher.
  </description>

  <executable>%BASE%\app\.venv\Scripts\python.exe</executable>

  <arguments>-u "%BASE%\app\recovery_worker.py" --continuous --interval 10 --limit 25 --health-file "%BASE%\health\recovery-health.json"</arguments>

  <workingdirectory>%BASE%\app</workingdirectory>

  <env name="PYTHONUNBUFFERED" value="1" />
  <env name="PYTHONUTF8" value="1" />

  <startmode>Automatic</startmode>
  <delayedAutoStart>true</delayedAutoStart>

  <stoptimeout>5 min</stoptimeout>

  <onfailure action="restart" delay="10 sec"/>
  <resetfailure>1 hour</resetfailure>

  <logpath>%BASE%\logs</logpath>
  <log mode="roll-by-size">
    <sizeThreshold>10485760</sizeThreshold>
    <keepFiles>10</keepFiles>
  </log>
</service>

9. Register and start (Admin Terminal):
# Install the Windows service
.\LGResearchRecovery.exe install

# Start the service
.\LGResearchRecovery.exe start

# Check service status
.\LGResearchRecovery.exe status

IMPORTANT NOTE: If you have a different IP or DNS address for your frontend, make sure it is
listed under the environment variable LG_RESEARCHER_ALLOWED_ORIGINS in the XML below.

<service>
  <id>LGResearchAPI</id>
  <name>LG Research API</name>

  <description>
    FastAPI service for the LangGraph Researcher application.
  </description>

  <executable>%BASE%\app\.venv\Scripts\python.exe</executable>

  <arguments>
    -m uvicorn api.main:app --host 127.0.0.1 --port 8000
  </arguments>

  <workingdirectory>%BASE%\app</workingdirectory>

  <env name="PYTHONUNBUFFERED" value="1"/>
  <env name="PYTHONUTF8" value="1"/>
  <env name="LG_RESEARCHER_ALLOWED_ORIGINS" value="http://localhost:5173,http://127.0.0.1:5173,http://127.0.0.1:8000" />
  <env name="RESEARCH_RECOVERY_HEALTH_FILE" value="C:\Services\LGResearchRecovery\health\recovery-health.json" />

  <startmode>Automatic</startmode>
  <delayedAutoStart>true</delayedAutoStart>

  <onfailure action="restart" delay="10 sec"/>

  <stoptimeout>30 sec</stoptimeout>

  <logpath>%BASE%\logs</logpath>

  <log mode="roll-by-size">
    <sizeThreshold>10240</sizeThreshold>
    <keepFiles>10</keepFiles>

Installation Instructions (React Frontend)

Note: Make sure Node and NPM are installed.

1. Navigate to the folder called 'Services' on C:
2. Create a sub folder called 'LGResearchFrontend'
3. Navigate to the frontend folder in LGResearcher source.  Run the following commands:

    npm ci
    npm run build
4. Download Caddy and copy to LGResearchFrontend and rename it caddy.exe.
https://caddyserver.com/download
5. Create a file called 'Caddyfile' with the following contents:

http://localhost:8080 {
    root * C:/Services/LGResearchFrontend/dist

    encode gzip zstd

    @api {
        path /api /api/*
    }

    handle @api {
        reverse_proxy 127.0.0.1:8000
    }

    handle {
        try_files {path} /index.html
        file_server
    }
}
6. run '.\caddy.exe fmt --overwrite' to format the Caddyfile.  Test Caddy:
.\caddy.exe validate --config Caddyfile --adapter caddyfile

.\caddy.exe run --config Caddyfile --adapter caddyfile

Navigate to localhost:8080.  Confirm that the site is visible.  Then terminate caddy (CTRL->C)

7. Copy the foldere /frontend/dist from the LGResearcher source to LGResearchFrontend
8. Create a folder called logs
9. Create LGResearchFrontend.xml in the LGResearchFrontend folder and add the following:


<service>
  <id>LGResearchFrontend</id>
  <name>LG Research Frontend</name>

  <description>
    Caddy web server hosting the LG Researcher frontend.
  </description>

  <executable>%BASE%\caddy.exe</executable>

  <arguments>
    run --config "%BASE%\Caddyfile" --adapter caddyfile
  </arguments>

  <workingdirectory>%BASE%</workingdirectory>

  <startmode>Automatic</startmode>
  <delayedAutoStart>true</delayedAutoStart>

  <onfailure action="restart" delay="10 sec"/>

  <logpath>%BASE%\logs</logpath>

  <log mode="roll-by-size">
    <sizeThreshold>10240</sizeThreshold>
    <keepFiles>10</keepFiles>
  </log>
</service>


10. Register and start (Admin Terminal):
# Install the Windows service
.\LGResearchFrontend.exe install

# Start the service
.\LGResearchFrontend.exe start

# Check service status
.\LGResearchFrontend.exe status
